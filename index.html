auto-eval-platform

Self-serve LLM evaluation infrastructure. 5 agents run continuously: golden sets, red team, gate synthesis, drift, compliance.

View on GitHub Read the README

Agents

Golden Set Agent

Generate, curate, version and refresh golden sets (kappa ≥ 0.8, SHA-256 freeze).

Red Team Agent

Prompt injection, jailbreak, PII leakage, hallucination, schema violation — nightly.

Gate Synthesis Agent

Bootstrap CI → 3-scenario gates (pessimistic/base/optimistic).

Drift Agent

PSI/KL on embeddings → alerts + auto-retraining triggers.

Compliance Agent

Regulations/DPAs → executable test suites + SHA-256 audit trails.
